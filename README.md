# IEPRFDV-Constellate!

Constellate! is a co-op roguelike game developed by Polarisda Studios, where sharing keeps you alive, but stealing might make you unstoppable 🚀

Side-by-side, defeat hordes of cosmic enemies to earn points in this co-op roguelike bullet hell. Each round survived together, a chest appears: share the loot with the other player, or steal it all for yourself! But when both players decide to steal, no one gets anything. The player with the most points wins!
